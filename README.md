🎯 Darts Game Counter
About the Project

Darts Game Counter is a Python-based application designed to help dart players keep track of their scores during a match.

The application is developed using Python 3.9, with a graphical user interface (GUI) built using the Tkinter library.

The main goal of this project is to provide a simple and intuitive scoring tool that makes tracking scores easier and helps players focus on their game.

This project was also developed as a personal learning experience to explore Python GUI development, Object-Oriented Programming (OOP), and software design principles.

✨ Features

The application currently offers the following features:

Game Mode Selection: Choose the game mode you want to play.
Score Tracking: Enter and track each player's score at every turn.
Scoring Assistance: Get guidance from the application to help record scores correctly.
🚧 Planned Features

The following features are planned for future releases but have not yet been implemented:

Player Profiles: Create custom player avatars and store player information in a database.
Player Statistics: Generate statistics and performance insights for each player profile.
Additional Game Modes: Expand the available game modes to support more dart variations.
🚀 Getting Started
Installation and Launch
Download or clone the repository.
Make sure Python 3.9 is installed on your system.
Navigate to the project directory.
Launch the application by running:
bash
python run.py

🛠️ Development Setup

If you want to contribute to the project or explore the source code, follow these steps to set up your development environment.

1. Create a virtual environment
bash
python -m venv .venv

2. Activate the virtual environment

Windows:

bash
.venv\Scripts\activate


Linux / macOS:

bash
source .venv/bin/activate

3. Upgrade development tools
bash
python -m pip install --upgrade pip setuptools

4. Install the project and development dependencies
bash
pip install -e ".[dev]"

📦 Building the Project

To build the project distribution packages, run:

bash
tox -e build


This command uses Tox to execute the project's build environment.
